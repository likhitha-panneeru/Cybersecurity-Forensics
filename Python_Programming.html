1 — Python Introduction & Fundamentals

1. Introduction to Python

Python is a high-level, general-purpose programming language known for readable syntax and a large ecosystem of libraries. In this module, the goal is not merely to memorize syntax: you should understand how Python represents data, makes decisions, repeats work, organizes code into functions/classes, handles files and exceptions, and connects to security/forensics libraries.

Why Python is useful

  • Readable syntax makes programs easier to write and maintain.
  • It supports procedural, object-oriented and functional programming styles.
  • It has a large standard library plus third-party packages.
  • It is widely useful for automation, scripting, data processing, networking and security tooling.
Mental model: a Python program is a sequence of statements. Values live in objects; names refer to objects; expressions produce values; control structures decide which statements execute.

2. Python Installation

Install a current Python 3 distribution from an official Python distribution for your operating system. During Windows installation, enabling the option to add Python to PATH makes command-line use easier.

Verify installation

python -c "print('Hello, Python')"

If python is not recognized, check the installation and PATH. On systems where python3 is the command, use that form.

3 — Loops & Iteration

Iteration / Looping Statements

Loops repeat a block of code. The syllabus covers for and while loops, loop-else, break, continue and nested loops.

for loop

for x in [10, 20, 30]:
    print(x)

while loop

n = 5
while n > 0:
    print(n)
    n -= 1

Loop else

The else attached to a loop executes when the loop finishes normally, not when it is terminated by break.

for x in range(5):
    if x == 8:
        break
else:
    print("Loop completed without break")

break and continue

  • break: exits the nearest loop.
  • continue: skips the remainder of the current iteration and moves to the next iteration.

Nested loops

for i in range(3):
    for j in range(3):
        print(i, j)

Practical programs

Factorial

n = int(input("n: "))

for i in range(1, n + 1):
    fact *= i
print(fact)

Reverse a number

n = int(input("n: "))
rev = 0
while n:
    digit = n % 10
    rev = rev * 10 + digit
    n //= 10
print(rev)

Prime check

n = int(input("n: "))
if n < 2:
    print("Not prime")
else:
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            print("Not prime")
            break
    else:
        print("Prime")

Nested loops

for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end=" ")
    print()
Understand, don't memorize: the prime program only needs to test divisors up to the square root because a composite number must have a factor no greater than its square root.

Caesar Cipher and ROT-13

The PDF introduces Caesar cipher as a simple substitution technique where each plaintext letter is replaced by a letter a fixed number of positions down the alphabet. It specifically uses ROT-13, a shift of 13, and supplies a dictionary mapping letters to their ROT-13 counterparts. Because the English alphabet has 26 letters, applying ROT-13 twice returns the original text.

import string

def rot13(text):
    lower = string.ascii_lowercase
    upper = string.ascii_uppercase
    result = []
    for ch in text:
        if ch in lower:
            result.append(lower[(lower.index(ch)+13) % 26])
        elif ch in upper:
            result.append(upper[(upper.index(ch)+13) % 26])
        else:
            result.append(ch)
    return "".join(result)

msg = input("Text: ")
print(rot13(msg))
Decode the syllabus message: Pnrfne pvcure? V zhpu cersre Pnrfne fnynq! becomes “Caesar cipher? I much prefer Caesar salad!” when ROT-13 is applied.

Security note: ROT-13/Caesar cipher is a teaching example, not modern secure encryption.

7 — Functions

User-Defined Functions

A function packages reusable logic. It is defined with def and can accept parameters and return a value.

def greet(name):
    return "Hello " + name

print(greet("Zuzu"))

Arguments and Parameters

A parameter is the name in the function definition; an argument is the value supplied when calling the function.

Positional/Required arguments

def add(a, b):
    return a + b
add(2, 3)

Default arguments

def cube(n=2):
    return n ** 3
print(cube())
print(cube(4))

Keyword/named arguments

def volume(length, width, height):
    return length * width * height
volume(height=2, length=3, width=4)

Returning values

return sends a result back to the caller and ends that function execution at that point.

Scope of variables

A local variable normally belongs to the function in which it is created. A global name exists at module level. Prefer passing values into functions and returning results rather than relying heavily on mutable global state.

Mutability of arguments and function calls

Python passes object references by assignment. If a function mutates a mutable object such as a list, the caller can observe that mutation; rebinding the local parameter to another object does not rebind the caller's name.

def add_item(items):
    items.append("new")

x = []
add_item(x)
print(x)  # ['new']

9 — Exception Handling

Exceptions

An exception is an event raised during execution that interrupts normal flow unless it is handled. Examples include ValueError, TypeError, IndexError, KeyError, FileNotFoundError and ZeroDivisionError.

Default exception handling

If an exception is not handled, Python prints a traceback and terminates the current program execution.

Exception hierarchy

Exceptions are organized in a class hierarchy. BaseException is at the top; common application exceptions derive from Exception. This is why catching Exception is broad, while catching a specific exception is usually clearer.

try–except

try:
    n = int(input("Number: "))
except ValueError:
    print("Please enter an integer.")

Multiple except blocks

try:
    a = int(input())
    print(10 / a)
except ValueError:
    print("Invalid integer")
except ZeroDivisionError:
    print("Cannot divide by zero")

finally

finally runs whether an exception occurred or not, making it useful for cleanup.

try:
    f = open("data.txt")
    print(f.read())
except FileNotFoundError:
    print("Missing file")
finally:
    print("Cleanup step")

else with try/except/finally

The else block runs when the try block completes without an exception.

try:
    x = int(input())
except ValueError:
    print("Invalid")
else:
    print("Valid:", x)
finally:
    print("Done")
Good practice: catch the narrowest expected exception. Avoid using a bare except: unless you have a very specific reason.

Practical

Write small programs that intentionally cause ValueError, ZeroDivisionError, IndexError and FileNotFoundError, then handle each appropriately.

10 — Classes, Objects, Inheritance & Operator Overloading

Classes and Objects

Object-oriented programming organizes data and behavior together. A class is a blueprint; an object/instance is a concrete object created from that class.

class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def display(self):
        print(self.name, self.salary)

e = Employee("Asha", 50000)
e.display()

self variable

self refers to the current instance when instance methods are called. It lets methods access that object's instance attributes.

Instance variables and methods

Instance variables belong to individual objects. Instance methods operate on an instance, normally through self.

Class variables and methods

A class variable is associated with the class and can be shared by instances. A @classmethod receives cls and operates at the class level.

class Employee:
    company = "Example"

    @classmethod
    def show_company(cls):
        print(cls.company)

Operator Overloading

Python lets classes define special methods such as __add__, __eq__ and __str__ to give operators/operations class-specific behavior.

class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        return Point(self.x + other.x, self.y + other.y)

Inheritance

Inheritance allows a child class to reuse/extend behavior from a parent class.

class Animal:
    def speak(self):
        print("sound")

class Dog(Animal):
    def bark(self):
        print("woof")

d = Dog()
d.speak()
d.bark()

Practical — Employee class

11 — Scapy, ipaddress, dns & dnslib

scapy Library

Scapy is a packet manipulation and network-analysis library. It can construct, dissect, send and inspect packets in authorized environments. For forensic/security learning, focus on understanding packet layers and reading captured traffic rather than generating traffic against systems without permission.

from scapy.all import IP, TCP
p = IP(dst="192.0.2.10")/TCP(dport=80)
p.show()

Concepts to know

  • Layering: packets can be stacked such as IP/TCP.
  • Fields: protocols expose fields such as addresses and ports.
  • Dissection: Scapy interprets raw bytes according to protocol structures.

ipaddress Module

The standard ipaddress module provides objects for IPv4/IPv6 addresses and networks.

import ipaddress
ip = ipaddress.ip_address("192.0.2.10")
net = ipaddress.ip_network("192.0.2.0/24")
print(ip.version)
print(ip in net)

Know the difference between an address and a network, and understand CIDR notation.

dns Module

The syllabus includes the dns module. In Python environments this commonly refers to DNS functionality supplied by the dnspython package. It can represent DNS queries, names and records.

import dns.resolver
answer = dns.resolver.resolve("example.com", "A")
for r in answer:
    print(r)

DNS terms to know: resolver, query, response, A record, AAAA record, MX record, CNAME, TTL and nameserver.

dnslib Library

dnslib is a Python library for constructing/parsing DNS packets and records.

from dnslib import DNSRecord
packet = DNSRecord.question("example.com")
print(packet)

12 — Beautiful Soup, telnetlib, win32evtlog, os, winreg & wmi

Beautiful Soup Library

Beautiful Soup parses HTML/XML and provides a convenient way to navigate a document tree. It is useful for extracting structured information from HTML that you are authorized to process.

from bs4 import BeautifulSoup

html = "<html><body><h1>Hello</h1></body></html>"
soup = BeautifulSoup(html, "html.parser")
print(soup.h1.get_text())

Important terms: tag, attribute, element, DOM-like tree, selector/search and text extraction.

telnetlib Module

The syllabus includes telnetlib. Telnet is a legacy remote-terminal protocol that does not provide modern encrypted transport. Learn the protocol and module concept in the context of controlled lab systems; do not use it to access systems without authorization.

win32evtlog Module

Python's Windows extensions can expose Windows Event Log functionality. The syllabus specifically lists win32evtlog for familiarization.

For forensics, connect this to the concept of event records: timestamp, source, event ID, level, message/data and log channel.

os Module

The os module provides operating-system interfaces.

import os
print(os.getcwd())
print(os.listdir("."))
print(os.path.exists("data.txt"))

Also know paths, environment variables, directory operations and process-related interfaces at a conceptual level.

winreg Module

winreg provides access to the Windows Registry from Python on Windows. Registry access can be sensitive because changing keys may affect the system; for forensic work, prefer reading from controlled evidence or exported registry hives when appropriate.

import winreg
key = winreg.OpenKey(winreg.HKEY_CURRENT_USER, r"Software")
print(winreg.QueryInfoKey(key))

wmi Module

WMI (Windows Management Instrumentation) exposes management information about Windows systems. It can be used to query system configuration and management data in authorized environments.

import wmi
c = wmi.WMI()
for item in c.Win32_OperatingSystem():
    print(item.Caption)

win32 clipboard Module

The syllabus lists the Windows clipboard functionality. Clipboard contents can be useful in troubleshooting or authorized endpoint analysis because users may temporarily copy text/data.

try:
    data = win32clipboard.GetClipboardData()

    win32clipboard.CloseClipboard()

libratom Library

The syllabus lists libratom as a library to familiarize yourself with. In the forensic context, it relates to processing certain Windows forensic artifacts/formats. The exact APIs available depend on the installed version and lab environment, so learn the functions actually supplied in your environment rather than assuming a version-specific API.

Cryptography using PyCrypto

The syllabus explicitly includes cryptography using PyCrypto. PyCrypto is an older cryptographic library; modern Python projects generally use maintained alternatives such as PyCryptodome or carefully selected standard/approved cryptographic libraries. For your syllabus, understand the cryptographic concepts and the APIs demonstrated by your lab version.

Core cryptography terms

  • Plaintext: original readable data.
  • Ciphertext: transformed encrypted data.
  • Key: secret/parameter controlling a cryptographic operation.
  • Encryption: plaintext → ciphertext.
  • Decryption: ciphertext → plaintext.
  • Hashing: one-way digest generation; not the same as encryption.
Security distinction: ROT-13 and Caesar cipher are substitution examples, not secure modern encryption. Never use them to protect real secrets.
14 — WinReg, PyPDF, Imaging Library & Dpkt

WinReg

The syllabus includes WinReg as both a lecture topic and a practical application. The Windows Registry stores configuration information in a hierarchical structure.

Registry concepts

  • Hive: major registry data file/logical root grouping.
  • Key: container similar to a directory.
  • Value: named data stored under a key.
  • Data type: describes how the value is represented.

Practical — read the Windows Registry

import winreg

path = r"Software\Microsoft\Windows\CurrentVersion"
key = winreg.OpenKey(winreg.HKEY_CURRENT_USER, path)

for i in range(winreg.QueryInfoKey(key)[1]):
    name, value, kind = winreg.EnumValue(key, i)
    print(name, value, kind)

Use a lab Windows VM. Registry modification is deliberately not part of this read-focused exercise.

Dpkt

dpkt is a Python library for parsing low-level network packets and protocol data, making it useful when automating PCAP analysis.

import dpkt
import socket

with open("capture.pcap", "rb") as f:

    for ts, buf in pcap:
        eth = dpkt.ethernet.Ethernet(buf)
        print(ts, type(eth.data).__name__)

Practical 1 — WinReg to Read the Windows Registry

Goal: retrieve selected registry information programmatically while keeping the exercise read-only.

Practical 2 — Recover Deleted Items in the Recycle Bin

The PDF explicitly asks for using Python to recover deleted items in the Recycle Bin. The exact implementation depends on Windows version, Recycle Bin artifact structure and the lab's intended method.

Concepts to understand

  • Deleting a file is not necessarily the same as securely erasing its underlying data.
  • The Recycle Bin stores deleted items and associated metadata before final removal.
  • Forensic recovery should be performed on a forensic image or controlled evidence copy whenever possible.
  • Do not modify a live user's Recycle Bin while attempting to investigate it.
Recommended lab: create a disposable test file inside a Windows VM, delete it normally, then examine the VM's Recycle Bin-related artifacts using a forensic image or a read-only forensic tool. Use Python to parse/export metadata rather than altering the source.

Practical 4 — Read EXIF Metadata from Images

from PIL import Image
from PIL.ExifTags import TAGS

img = Image.open("photo.jpg")
exif = img.getexif()

for tag_id, value in exif.items():
    tag = TAGS.get(tag_id, tag_id)
    print(tag, ":", value)

Potential EXIF fields include camera make/model, software, orientation, timestamps and sometimes GPS-related data. Availability varies by image and processing history.

Practical 5 — Parse Firefox SQLite3 Databases with Python

Firefox stores some browser information in SQLite databases. The exact schema can vary by browser/version/profile.

import sqlite3

    print(row)

Forensics concepts: browser history, URLs, visit timestamps, downloads, cookies and profile databases. Always work from a copied forensic artifact and use parameterized SQL when user input is involved.

query = "SELECT url, title FROM moz_places LIMIT ?"

Practical 6 — Parse Packets with Dpkt

import dpkt
import socket

with open("capture.pcap", "rb") as f:
    reader = dpkt.pcap.Reader(f)
    for ts, buf in reader:
        eth = dpkt.ethernet.Ethernet(buf)
        if isinstance(eth.data, dpkt.ip.IP):
            ip = eth.data
            src = socket.inet_ntoa(ip.src)
            dst = socket.inet_ntoa(ip.dst)
            print(ts, src, "->", dst, type(ip.data).__name__)

Learn to connect packet bytes to Ethernet → IP → TCP/UDP → application-layer structures. Correlate packet timestamps with host evidence where possible.

PairDifference
List vs TupleBoth ordered; list is mutable, tuple is immutable.
Dictionary vs ListDictionary maps keys to values; list uses positional indexing.
Parameter vs ArgumentParameter appears in definition; argument is supplied at call time.
Module vs LibraryModule is a reusable Python unit; library is a broader reusable collection.
Function vs MethodA method is a function associated with an object/class context.
Exception vs Syntax errorSyntax errors prevent valid parsing; exceptions arise during execution.
Encryption vs HashingEncryption is reversible with the proper key; hashing is designed as a one-way digest.
ROT-13 vs secure encryptionROT-13 is a simple substitution teaching example and is not cryptographically secure.
